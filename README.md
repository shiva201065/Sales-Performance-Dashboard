# Sales-Performance-Dashboard

## Overview
Interactive Sales Performance Dashboard built using Power BI to analaise sales trends, profit performance, and customer insights.

## Tools Used
- Power BI
- DAX
- CSV Dataset

## Features
- Sales Analysis
- Profit Analysis
- Regional Performance
- Interactive Filters and Slicers
